Kingdom Hearts Modding Index

The Kingdom Hearts Modding Index is a research and reference database dedicated to understanding the internal data and systems behind the Kingdom Hearts PC games.

This site documents information discovered through reverse engineering, game-data research, memory research, Cheat Engine experimentation, asset analysis and hands-on modding.

A major focus of the project is understanding the game's data files and the way different assets, identifiers, variables and resources are organized and used by the game.

What You'll Find Here

The Index brings together research and documentation covering characters, worlds, internal identifiers, variables, assets, file formats, tools and other information useful for Kingdom Hearts modding.

Some of this information comes from direct experimentation and reverse engineering, while other information is built through examining game files, testing values in-game, analyzing assets and comparing discovered data.

The goal is to turn scattered discoveries into organized documentation that can be referenced by other modders and researchers.

Research & Reverse Engineering

This database covers research involving game memory, Cheat Engine, executable behavior, internal variables, character data, world data, asset structures and the relationships between the different systems used by the game.

It also documents findings from investigating Kingdom Hearts data archives and individual file types, including BIN, HED, PKG, WPN, DAT, DDS, MDLX, MDLS, TM2, MSET and other resources.

Asset Hashing & Cross-Reference Research

Asset identification and hashing is another part of the research documented by this Index.

During the investigation of Kingdom Hearts assets, information from the OpenKH project was used as a reference for cross-referencing asset hashes and identifying relationships between hashed resources and their corresponding game assets.

These references were then compared against independently examined game files and in-game behavior to help verify and document the information within this database.

OpenKH is credited as a reference for the relevant hashing and asset-identification information. The Index is intended to build upon that research through additional experimentation, verification and documentation.

An Ongoing Reference

This is an ongoing research project. New discoveries, identifiers, file structures, tools and documentation will be added as the game's data is investigated further.

The information presented here is intended to help people understand how Kingdom Hearts works internally and provide a foundation for creating and researching mods.

Assets

Kingdom Hearts file formats, archive structures and researched asset relationships used throughout KH1 and KH2.

.BIN

Binary game data used to store structured, packed or otherwise game-specific resources. BIN files may contain multiple types of data depending on the archive or system they belong to.

Format Binary Container / Data
Purpose Stores game data and binary resources used by Kingdom Hearts systems.
Research Status Structure varies by file and requires format-specific inspection.

.HED

Archive header data used to describe the contents of associated package data. HED files can be used to locate and identify resources stored within corresponding package archives.

Format Archive Header
Purpose Provides metadata and entry information used when accessing archived resources.
Related Files Commonly associated with PKG data.

.PKG

Package data containing archived game resources. PKG files work alongside archive metadata to provide access to the underlying resources stored within the game's data archives.

Format Package / Archive Data
Purpose Stores packed game resources referenced by archive information.
Related Files HED archive headers.

.WPN

Weapon-related resource files used by Kingdom Hearts. WPN containers may contain weapon data, models and embedded texture resources depending on the specific asset.

Format Weapon Resource
Purpose Stores resources associated with weapons and weapon-related game objects.
Known Contents May contain embedded texture resources such as DDS data.

.DAT

Extracted game data commonly encountered during archive and container processing. DAT files can represent resources that were originally stored inside larger packed game data structures.

Format Game Data
Purpose Stores extracted resources from packed Kingdom Hearts game data.
Extraction Sources PKG, HED and related archive/container data.

.DDS

DirectDraw Surface texture data used for graphical resources. DDS textures can be embedded within several Kingdom Hearts asset formats and may be extracted during asset analysis.

Format Texture
Purpose Stores texture and graphical image data used by game assets.
Known Sources TM2, CVBL, WPN, MDLS and MDLX resources.

.MDLX

Kingdom Hearts 2 model-related resources used for character, enemy, object and other 3D game assets. MDLX files may contain model structures and associated graphical resources.

Format 3D Model Resource
Game Kingdom Hearts 2
Known Contents Model data and potentially embedded texture resources.

.MDLS

Kingdom Hearts 1 model-related resources used for characters, enemies, objects and other three-dimensional game assets.

Format 3D Model Resource
Game Kingdom Hearts 1
Known Contents Model structures and associated graphical resources.

.MSET

Motion and animation resources associated with characters, enemies and other animated game objects. MSET data is used alongside model resources to provide animation behavior.

Format Motion / Animation Resource
Purpose Stores animation and motion data used by game entities.
Related Resources Character models, MDLS and MDLX assets.
